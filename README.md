# Liquid movement demo

A single-file, browser-based discussion demo for Electio. Open `index.html` directly. No installation, network access, telemetry, external libraries, or backend required.

## What it shows

- A synthetic pad and event/context/model flow inspired by the supplied liquid slug optimization screenshot.
- Editable scenario, starting tank level, arrival volume, and drain capacity.
- A transparent tank mass-balance forecast with an operator review threshold.
- A fictional pad route and synthetic observations.

Every datum is generated for demonstration. The model is deliberately a simple baseline, not a field-validated predictor or control system. It does not infer leaks or equipment faults.

## References that informed the framing

- [A3DBR](https://github.com/LBNL-ETA/a3dbr): drone imagery to building footprints and heights.
- [TAR](https://github.com/LBNL-ETA/TAR): thermal anomaly and rooftop-unit detection.
- [Sensor Suitcase award](https://bies.lbl.gov/news/sensor-suitcase-wins-award-excellence): streamlined sensing and automated analysis through a lab-industry commercialization path.
- [RMV2.0](https://github.com/LBNL-ETA/RMV2.0): transparent baseline modeling, savings estimates, and non-routine event screening.

This is an independent synthetic example; no LBNL code or datasets are included.
