# skillssearch

Data Mining & Natural Language Processing on Public Health Job Data.

This codebase includes web scraping code to pull information from a job site and process it to extract relevant skills.

## Electio liquid movement demo

A standalone browser demonstration is available in [`electio-demo/`](electio-demo/). It uses synthetic events and a transparent tank balance to illustrate liquid arrival forecasting. The demo includes a dimensioned OpenReynolds case prompt, a chart trace importer, and clear labels separating preview values from solver output. Open `electio-demo/index.html` directly; no installation or server is required. Running OpenReynolds requires separate workspace and model credentials.
